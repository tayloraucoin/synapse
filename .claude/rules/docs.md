# Docs

- Templates (`*.template.md`) stay blank. A filled copy lives with its product (the demo's under `apps/web/docs/` and `specs/`), never inside `docs/`.
- A filed thread output (`docs/research/`, the verbatim prompts, role bodies) keeps its body byte for byte; a correction is a new file or an amendment block.
- To change the practice: amend the file, add a ledger line or a `docs/decisions/changelog.md` entry, and a record only when the reason needs more than one line. Nothing lives in two places.
