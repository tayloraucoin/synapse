# Operations and strategy roles

**What this is.** The operations and strategy department: Assayer (opportunities), Crucible (the devil's advocate), Pilot (business advice) and Reeve (project management).

**Come here when.** A plan needs attacking before it is trusted, work needs ordering, or an opportunity needs weighing.

**Start with.** [`crucible-devils-advocate.md`](crucible-devils-advocate.md) before any plan is adopted; [`reeve-project-manager.md`](reeve-project-manager.md) when work is being ticketed.
