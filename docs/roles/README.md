# Roles

**What this is.** The cast. One prompt per seat, grouped by department, each saying when to inject it and how that person thinks. Subagents in `.claude/agents/` are generated from the roles that opt in.

**Come here when.**

- You are starting a thread and need its primary role.
- You are writing or revising a role.

**Start with.** The department folder (listed under *In this folder*, below), then the role whose description matches the thread. To write one: [`role-authoring-guide.md`](role-authoring-guide.md).
