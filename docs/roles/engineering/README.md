# Engineering roles

**What this is.** The engineering department. Mason rules on architecture, Lorimer on the agent harness, Quartermaster on the stack, Touchstone on tests, Warden on security, Vigil on QA, Scribe on docs, Usher on onboarding, Millwright on platform, Turner on design engineering, and the specialists beside them.

**Come here when.** The work touches code, infrastructure, the stack, the harness or how someone becomes productive in the codebase.

**Start with.** The role whose description names your thread. Most engineering threads inject one role and consult the others by function.
