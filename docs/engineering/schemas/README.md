# Engineering schemas

**What this is.** The shapes the work loop's files must have, as JSON Schema: `contract.schema.json` (a contract's frontmatter) and `results.schema.json` (a ticket's results, written only by tooling). `check-specs` validates every contract and results file against these, through `tooling/lib/json-schema.ts`, so each shape has one home. The rules a schema cannot carry (one surface per ticket, reviewers by path, the 1,000-token cap) are in `tooling/lib/specs.ts`.

**Come here when.** A check names one of these files, or you are porting the loop.

**Start with.** The template that fills each shape: `docs/engineering/templates/contract.template.md`.
