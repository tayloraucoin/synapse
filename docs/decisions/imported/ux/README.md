# The older UX layers

Copies of seven superseded docs in `docs/ux/`, byte for byte, kept here as the archive PEM names for them. The originals stay in `docs/ux/` until MIG-1 closes and moves them (then these copies become the only ones); until then `docs/ux/` is the copy every spec cites. Links inside them were written for `docs/ux/`, and some do not resolve from here. What is still read from them is listed in [`../../../ux/README.md`](../../../ux/README.md); MIG-1 carries what still holds into [`specs/web/ux/`](../../../../specs/web/ux/).
