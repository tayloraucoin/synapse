# Decision records

**What this is.** Numbered records, `0001` onward, never renumbered. Each follows `../decision.template.md`: context, options, the decision, consequences, and the trigger that reopens it.

**Come here when.** A ledger line cites `REC NNNN`, or you are about to make a choice with real alternatives that a later session might re-argue.

**Start with.** The record the ledger points you to. To write one, copy the template, take the next free number, and add the ledger line.
