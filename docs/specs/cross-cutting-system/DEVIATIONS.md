2026-09-05 · SYS-1 · **`main` moved from `AppShell` into `PageFrame`**, rather than staying in `AppShell` as the ticket's "The skip link and `main#main` move into `AppShell` (already there)" says · The ticket also requires `AppHeader` to be a `banner` landmark, and the two cannot both be true: a `<header>` is only a banner while it is NOT inside `main`, and every page's header is rendered by the page — from inside `AppShell`'s children, which were inside `main`. Keeping the landmark relationship cross-cutting §3.4 names (banner → complementary → main) meant giving the page the whole column. The skip link stays in `AppShell`, first in the DOM, and still targets `#main`. **The consequence, stated:** a `(shell)` page that does not render a `PageFrame` has no `main` and a dead skip link — which is already the ticket's rule, now load-bearing.
2026-09-05 · SYS-1 · `ShellPageHeader` (`components/page-frame/`) was added; the ticket names only `PageFrame` · `PageFrame` takes a header NODE because feature screens need a save status, an action, or a `DayHeader` as the title. Twenty-six placeholder pages need none of that, and twenty-six hand-assembled `AppHeader`s is twenty-six chances to drop the avatar or the back arrow. The standard header is one component; `PageFrame`'s signature is unchanged.
2026-09-05 · SYS-1 · `PageFrame`'s `dayKey` is optional, not required · The ticket's signature has it, but only the four day routes know a day; every other page would have had to fetch `shell.status` server-side purely to pass a value the status line already holds. Absent, it defaults to the query's `todayKey`.
2026-09-05 · SYS-1 · `StatusLineSlot` gained a `pendingText` prop · Official spec §10.5's line names the day and the count (*Yesterday has 3 items to review*), which the copy table cannot hold as a constant. The table keeps a generic fallback; `pendingReviewText(weekday, count)` builds the real one. The slot stays a pure resolver.
2026-09-05 · SYS-1 · `tabForPath` moved to `nav-items.ts` from its two copies in `tab-bar.tsx` and `rail.tsx` · SYS-1 needed a third reader (scroll memory, which is keyed per tab). Three copies of a prefix rule is three chances for the navigation, the highlight and the remembered scroll to disagree about which tab a route belongs to.
2026-09-05 · SYS-1 · `packages/utils/src/day/` was created here with `resolveDayKey`, `weekdayForDayKey` and `daysBefore`, though placement rule 6 assigns that folder to USE-1 · The shell cannot know which day it is rendering without the day-key rule, and USE-1 is not built. The file says USE-1 owns it and to extend rather than fork. Verified against sixteen cases including both DST transitions, month and year boundaries, and a zone where the calendar date and the day key disagree.
2026-09-05 · SYS-1 · `AppHeader`'s `h1` gained `tabIndex={-1}` and `outline-none` · The ticket rules the first; the second is its consequence. Focus here is programmatic (a tab switch) and announces itself by being read — a focus ring around a heading nobody clicked reads as a rendering bug.
