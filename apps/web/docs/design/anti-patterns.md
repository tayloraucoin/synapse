# Synapse — anti-patterns.md

Beyond A-01..A-20; binding (`apps/web/docs/product-rules.md`), so Blocking.

| ID    | Tell                                           | Instead                             |
| ----- | ---------------------------------------------- | ----------------------------------- |
| P-A01 | A score; adherence outside Review (A-19)       | Review only, formula in words       |
| P-A02 | A number about the day on the tabs             | Times and durations only            |
| P-A03 | Colour as the only signal                      | Dot and word, chip and name (C-P05) |
| P-A04 | Red on the tabs                                | Ink and a sentence                  |
| P-A05 | "you", or a question mark, on the tabs         | Statements; asks only in a sheet    |
| P-A06 | A notification of a miss, streak, % or absence | A scheduled fact, their words       |
| P-A07 | Past or done items disabled                    | Faded and live                      |
| P-A08 | Rewriting the record                           | Annotate: ghost, band               |
| P-A09 | Data visible beyond its owner                  | `ctx.rls.execute()`                 |
