# Test shape per risk

There is no `docs/engineering/test-strategy.md` yet (J11), so Touchstone's rule applies: the shape of a risk picks its test type. Vitest runs per workspace through `yarn test` (MIG-5); Playwright runs the journeys and captures. C7 sets the spend: tests go where a defect would cost data or trust, and everywhere else Taylor finds problems by using the app.

**There is no local database and no test ever writes to staging.** So nothing here is an integration test against Postgres. RLS is proven by a static check on the schema, and by Mason and Warden reading the SQL at Q3.

| Risk                                                                                              | Shape                     | Test                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------------------------------------------------------------------------------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| The clock gives a wrong time when taps arrive out of order, twice, or from two devices            | Combinatorial             | Generated inputs over `deriveClock`. Events are shuffled, duplicated and interleaved, and the invariants are asserted: inside a Work block, at most one open work span; firing never counts as work; a `done` beats a later `paused`; a replay is a no-op; a clamp applies at the day's close. A generator library is a new dev dependency, so Quartermaster rules on it; failing that, a seeded generator lives in the test file. |
| The repeat rule, or a dated change, lands on the wrong days                                       | Pure logic, with dates    | A unit table: each of Google's presets (D-USE-80) across a month, a leap day and both DST changes, plus `block_changes` moving or skipping one date.                                                                                                                                                                                                                                                                               |
| Next, fit, session counts, status fill, the while-it-fires pick, the pull rule, client resolution | Pure logic                | Unit tests, one file per function.                                                                                                                                                                                                                                                                                                                                                                                                 |
| A new table ships without owner-private RLS; `slot_events` can be edited                          | Owned boundary, static    | A check over `packages/db/src/schema/{planner,work,integrations}/`: every table carries the owner-private factory, and `slot_events` has no update or delete policy. Then Mason's and Warden's read of `0012` (Q3).                                                                                                                                                                                                                |
| A token reaches a router's output, or a browser bundle                                            | Owned boundary, static    | Every `linear` and `google` procedure's output schema has no token field (a unit test over the schemas). `token-crypto` is imported only by `services/{linear,google}/` (a boundaries rule).                                                                                                                                                                                                                                       |
| Linear's or Google's response is not the shape we parse; a write fails silently                   | Third-party boundary      | Contract tests: the zod schemas against recorded responses kept beside the tests, plus the outbox's pending → failed → sent path on a stubbed client. One manual live check for each Linear write (status, done, reopen) on Taylor's workspace.                                                                                                                                                                                    |
| An offline tap is lost, or replays out of order                                                   | Journey                   | End to end: go offline, fire, Done, reload, come back online. The events land once, in order, with their own times.                                                                                                                                                                                                                                                                                                                |
| The phone's loop breaks between taps                                                              | Journey                   | End to end at 402, on fixtures and again once wired: C-USE-firing-1, C-USE-sessions-1, and Step away with Resume all.                                                                                                                                                                                                                                                                                                              |
| The desk switches layout at the wrong width                                                       | Journey                   | End to end at 1023 and at 1024.                                                                                                                                                                                                                                                                                                                                                                                                    |
| A state looks wrong                                                                               | UI                        | Captures per `?state=` against the ledger's captures; Assay's UI audit.                                                                                                                                                                                                                                                                                                                                                            |
| iOS push on the installed app; the edge swipe in standalone mode; a phone tap seen at the desk    | Device and across devices | Manual, on Taylor's iPhone and a desk browser, recorded as operator checks.                                                                                                                                                                                                                                                                                                                                                        |
