# system-states — _global

## Job

When the app itself has something to say, say it once, in a sentence, with a door: a page that is not here, a screen that broke, a connection that went, a session that ended, a new version, a device in another zone, a home-screen slot. The person is often at their least patient here; nothing apologises, nothing shows a code.

## Layout and components

`ErrorPage` (two variants) inside its own `main#main`, no shell, one `h1`; `AlertDialog` for the session; `ConfirmDialog` for the zone switch; `ResponsiveSheet` through `SheetHost` for the platform steps; the `StatusLine` presets for offline, update and install (`shell.md`). Primary action: _Open today_ on not-found; _Reload_ on the error page; _Sign in_ on the session dialog; _Switch_ on the zone dialog.

## Words

As quoted. The session dialog's third sentence appears only with a running timer. The zone sentences name both zones in order. The install intro mentions iPhone and iPad by name; nothing else names a platform. No error code, stack or digest ever reaches the screen.

## Access

Not-found and error pages keep `main#main` so the skip link has a target; one `h1` each. The session dialog is `alertdialog`, focus trapped, Esc prevented, one action. The zone dialog is a confirm with cancel first. The steps sheet is an ordered list, announced with its title. Status lines are `status`, polite. Reduced motion: none of these move.

## Instrumentation

The error page logs `render error` with the message and digest through `@syn/observability`; nothing else fires.
